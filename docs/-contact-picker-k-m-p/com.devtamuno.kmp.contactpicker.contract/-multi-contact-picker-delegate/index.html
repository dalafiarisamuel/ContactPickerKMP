MultiContactPickerDelegate

private class MultiContactPickerDelegate(val onContactsSelected: (List<Contact>) -> Unit) : NSObject, CNContactPickerDelegateProtocol(source)

Delegate for multiple contact selection.

This delegate implements the CNContactPickerDelegateProtocol to handle the selection of multiple contacts from the native iOS contact picker.

By implementing the contactPicker(_:didSelectContacts:) method, the iOS contact picker automatically enables its multi-selection user interface, allowing users to select multiple contacts before finishing.

onContactsSelected

Callback invoked with the list of selected contacts.
